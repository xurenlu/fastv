# 波形窗口不显示问题排查和修复

## 问题描述

日志显示波形窗口已经创建和显示，但用户在屏幕上看不到窗口。

## 可能的原因

### 1. 窗口层级问题
**原因**：窗口层级设置为`.floating`可能被其他窗口遮挡
**修复**：改为`.statusBar`级别，确保显示在最前面

### 2. 窗口被自动释放
**原因**：`window.delegate`使用弱引用，WindowDelegate可能被立即释放
**修复**：
- 添加`window.isReleasedWhenClosed = false`
- 保持WindowDelegate的强引用

### 3. 窗口在错误的屏幕或位置
**原因**：多显示器环境下，窗口可能显示在其他屏幕
**修复**：添加详细的位置日志，使用`orderFrontRegardless()`强制显示

### 4. 窗口透明度或可见性问题
**原因**：窗口可能太透明或被隐藏
**修复**：
- 增强背景可见性（添加边框）
- 确保`alphaValue`正常
- 添加`hidesOnDeactivate = false`

## 已实施的修复

### 修复1：提升窗口层级

```swift
// 之前
window.level = .floating

// 现在
window.level = .statusBar  // 更高的层级，类似系统状态栏
```

### 修复2：防止窗口被释放

```swift
window.isReleasedWhenClosed = false  // 防止窗口被自动释放
window.hidesOnDeactivate = false     // 防止失去焦点时隐藏
```

### 修复3：强制显示窗口

```swift
DispatchQueue.main.async {
    window.orderFrontRegardless()  // 强制显示在最前面
    window.makeKeyAndOrderFront(nil)
}
```

### 修复4：增强视觉效果

```swift
// 添加边框，让窗口更明显
RoundedRectangle(cornerRadius: 20, style: .continuous)
    .fill(.ultraThinMaterial)
    .overlay {
        RoundedRectangle(cornerRadius: 20, style: .continuous)
            .strokeBorder(Color.accentColor.opacity(0.5), lineWidth: 2)
    }
    .shadow(color: .black.opacity(0.3), radius: 10, y: 5)
```

### 修复5：添加详细日志

### 修复6：添加测试按钮

在设置界面添加了"测试显示工具条"按钮：
- 点击后立即显示波形窗口
- 3秒后自动消失
- 方便快速测试窗口是否正常显示

## 常见问题排查

### Q1: 窗口位置不对，显示在屏幕外

**检查**：查看日志中的窗口位置
```
📊 [WaveformWindowManager] 窗口位置: x=..., y=..., width=120, height=40
```

**解决**：
1. 检查屏幕分辨率是否正确
2. 在设置中更改"悬浮工具条位置"
3. 尝试不同的位置选项

### Q2: 多显示器环境下窗口在其他屏幕

**检查**：查看日志中的screen信息
```
   - screen: ...
```

**解决**：
1. 确保主窗口在你想要显示波形窗口的屏幕上
2. 代码使用`NSScreen.main`，会显示在主屏幕
3. 如果需要显示在其他屏幕，需要修改代码

### Q3: 窗口层级太低，被其他窗口遮挡

**检查**：查看日志中的窗口层级
```
📊 [WaveformWindowManager] 窗口层级: 8
```

**说明**：
- `.statusBar` = 8 (最高)
- `.floating` = 3
- `.normal` = 0

**解决**：已修复为`.statusBar`级别

### Q4: 窗口在其他桌面空间

**检查**：查看日志
```
   - isOnActiveSpace: false
```

**解决**：
- 已添加`.canJoinAllSpaces`，窗口应该在所有空间显示
- 如果仍然不行，切换到其他桌面空间查看

### Q5: 全屏应用时窗口不显示

**检查**：是否在全屏应用中使用

**解决**：
- 已添加`.fullScreenAuxiliary`，应该在全屏时也显示
- 如果不行，退出全屏模式测试

## 技术细节

### 窗口层级说明

macOS窗口层级（从高到低）：
1. `.screenSaver` (1000) - 屏保
2. `.statusBar` (8) - 状态栏 ⭐ 我们使用这个
3. `.popUpMenu` (5) - 弹出菜单
4. `.modalPanel` (4) - 模态面板
5. `.floating` (3) - 浮动窗口
6. `.normal` (0) - 普通窗口

### 窗口行为标志

```swift
window.collectionBehavior = [
    .canJoinAllSpaces,      // 在所有桌面空间显示
    .stationary,            // 固定位置，不随窗口移动
    .fullScreenAuxiliary    // 全屏时也显示
]
```

### 坐标系统

macOS使用左下角为原点的坐标系：
- x: 从左到右增加
- y: 从下到上增加（注意：与iOS相反）

因此：
- 右上角：`(screenWidth - windowWidth - margin, screenHeight - windowHeight - margin)`
- 左上角：`(margin, screenHeight - windowHeight - margin)`
