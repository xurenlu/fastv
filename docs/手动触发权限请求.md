# 手动触发权限请求

## 🔍 当前状态

- ✅ 应用已复制到 `/Applications/fastv.app`
- ✅ Info.plist 配置正确
- ✅ Bundle ID: `com.wxside.fastv`
- ✅ 麦克风权限说明已配置
- ⚠️ TCC数据库中没有权限记录（说明还没请求过）

## 🎯 关键问题

**应用必须先请求权限，才会出现在系统设置的麦克风列表中！**

只有当应用调用 `AVCaptureDevice.requestAccess(for: .audio)` 后，系统才会：
1. 弹出权限对话框
2. 在系统设置中添加该应用到麦克风列表

## ✅ 解决方案

### 方法1：通过应用界面触发（推荐）

#### 步骤1：确保只运行Applications版本

```bash
# 关闭所有fastv进程
killall fastv

# 从Applications启动
open /Applications/fastv.app
```

#### 步骤2：在应用中触发权限请求

**选项A：使用语音输入功能**
1. 应用启动后，进入"设置"
2. 启用"语音输入法"
3. 设置快捷键为"左Control"
4. 按下Control键
5. 此时会触发麦克风权限请求
6. **应该会弹出权限对话框**

**选项B：使用测试按钮**
1. 应用启动后，进入"设置" → "语音输入法"
2. 点击"测试显示工具条"按钮
3. 虽然这个不会触发录音，但可以确认应用正常运行

#### 步骤3：观察权限对话框

**如果对话框弹出**：
```
┌─────────────────────────────────────────┐
│  "fastv" 想要访问您的麦克风              │
│                                         │
│  FastV 需要访问您的麦克风以进行语音      │
│  输入和语音转文字功能。                  │
│                                         │
│              [不允许]  [允许]            │
└─────────────────────────────────────────┘
```

点击"允许"！

**如果对话框没弹出**：
- 检查屏幕顶部的菜单栏
- 检查所有桌面空间
- 查看Mission Control中是否有窗口
- 继续看下面的方法2

### 方法2：手动添加到系统设置

如果权限对话框始终不弹出，可以手动添加：

#### 步骤1：打开系统设置

```bash
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Microphone"
```

或手动：
1. 打开"系统设置"
2. "隐私与安全性"
3. "麦克风"

#### 步骤2：解锁设置

点击左下角的🔒锁图标，输入密码解锁

#### 步骤3：添加应用

1. 点击列表下方的 **+** 号
2. 在文件选择器中按 `Command + Shift + G`
3. 输入路径：`/Applications`
4. 找到并选择 `fastv.app`
5. 点击"打开"
6. **确保勾选 fastv 旁边的复选框**

#### 步骤4：验证

```bash
sqlite3 ~/Library/Application\ Support/com.apple.TCC/TCC.db "SELECT service, client, allowed FROM access WHERE client='com.wxside.fastv';"
```

应该显示：
```
kTCCServiceMicrophone|com.wxside.fastv|1
```

### 方法3：使用命令行强制添加（高级）

⚠️ **注意**：这需要禁用系统完整性保护（SIP），不推荐！

```bash
# 查看当前SIP状态
csrutil status

# 如果SIP已禁用，可以直接修改TCC数据库
# 但这不推荐，因为需要重启到恢复模式
```

### 方法4：使用tccutil（如果可用）

某些macOS版本支持：

```bash
# 尝试直接授权（可能不工作）
sudo tccutil add Microphone com.wxside.fastv
```

## 💡 常见问题

### Q: 为什么对话框不弹出？

**可能原因**：
1. 应用没有正确调用权限请求API
2. 系统缓存了之前的拒绝决定
3. 应用签名有问题
4. 对话框在后台或其他桌面空间

**解决**：
- 完全退出应用重新启动
- 重置权限：`tccutil reset Microphone com.wxside.fastv`
- 手动添加到系统设置

### Q: 手动添加后还是不能录音？

**检查**：
1. 确保应用正在运行
2. 确保勾选了复选框
3. 重启应用
4. 查看日志是否有错误

### Q: 系统设置中看不到"+"号？

**原因**：设置被锁定

**解决**：点击左下角的🔒锁图标解锁

## 📝 总结

最简单的方法：

1. **关闭所有fastv进程**
   ```bash
   killall fastv
   ```

2. **从Applications启动**
   ```bash
   open /Applications/fastv.app
   ```

3. **按Control键触发权限请求**
   - 应该弹出对话框
   - 点击"允许"

4. **如果对话框不弹出，手动添加**
   - 系统设置 → 麦克风
   - 点击 + 号
   - 添加 /Applications/fastv.app
   - 勾选

5. **测试语音输入**
   - 按Control键
   - 说话
   - 松开
   - 查看转录结果

现在请尝试这些方法！
