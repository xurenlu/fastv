# AI 文本优化功能 v1.1 更新说明

## 🎉 新功能

### 1. ⏱️ 超时时间设置
- 可调节的超时滑块（2-30 秒）
- 实时显示当前超时值
- 智能建议：本地 2-5 秒，远程 10-30 秒

### 2. 🧪 测试文本优化
- **一键测试**：点击"测试文本优化"按钮
- **实际测试**：发送真实文本进行优化
- **性能评估**：显示响应时间和速度评级
- **对比展示**：查看优化前后的效果

## 📊 测试结果示例

```
✅ 测试成功

⏱️ 响应时间: 2.34 秒 ✅ 正常

📝 原始文本:
嗯那个我今天想去超市买点东西然后呢顺便看看有没有什么优惠活动

✨ 优化后:
我今天想去超市买点东西，顺便看看有没有什么优惠活动。
```

## 🚀 快速开始

### 第一步：配置
1. 打开设置 > AI 文本优化
2. 启用 AI 文本优化
3. 保持默认设置（端点、模型、超时 5 秒）

### 第二步：测试（重要！）
1. 点击"测试文本优化"按钮
2. 查看响应时间
3. 根据结果调整超时设置

### 第三步：调整
- 响应时间 < 3 秒 → 超时设置 3-4 秒 ⚡️
- 响应时间 3-5 秒 → 超时设置 5-7 秒 ✅
- 响应时间 > 5 秒 → 超时设置 8-10 秒或换模型 ⚠️

## 💡 推荐配置

### 最快配置（1-2 秒响应）
```
模型: qwen2:1.5b
超时: 3 秒
适合: 追求速度，实时输入
```

### 平衡配置（2-3 秒响应）
```
模型: gemma2:2b
超时: 5 秒
适合: 平衡速度和质量（推荐）
```

### 高质量配置（5-8 秒响应）
```
模型: qwen2:7b
超时: 10 秒
适合: 追求质量，可以等待
```

## 🎯 使用技巧

1. **先测试再使用**：每次更换模型或配置后，先点击"测试文本优化"
2. **留有余量**：超时时间建议比测试时间多 1-2 秒
3. **选择合适的模型**：实时语音输入建议使用 2B 以下的小模型
4. **关注响应时间**：控制台会显示每次优化的实际耗时
