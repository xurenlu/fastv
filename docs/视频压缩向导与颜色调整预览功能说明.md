# 视频压缩向导与颜色调整预览功能说明

## 概述

本次更新为 fastv 视频处理工具添加了两个重要的用户体验改进功能：

1. **智能压缩向导** - 根据目标文件大小自动推荐最佳压缩参数
2. **实时颜色调整预览** - 通过滑块对比查看调整前后的效果

## 一、智能压缩向导

### 功能特点

- 用户只需输入期望的文件大小，系统自动计算并推荐：
  - 最佳分辨率
  - 合适的帧率
  - 目标码率
  - CRF 值
  - 预估压缩比
  - 画质评级

### 使用方法

1. 在视频压缩页面，开启"使用智能向导"开关
2. 输入目标文件大小（支持 MB 和 GB 单位）
3. 查看系统推荐的参数
4. 点击"应用推荐参数"或手动微调
5. 开始压缩

### 技术实现

#### 新增文件

- `fastv/Services/VideoCompressionCalculator.swift` - 压缩参数计算服务
  - 码率计算算法
  - 分辨率推荐逻辑
  - 帧率优化建议
  - 画质评估系统

#### 修改文件

- `fastv/Services/VideoInfoService.swift` - 添加码率计算方法
- `fastv/Views/VideoTools/VideoCompressionView.swift` - 集成智能向导 UI

#### 核心算法

**码率计算公式**:
```
目标视频码率(bps) = (目标文件大小(bytes) × 8 / 视频时长(s)) - 音频码率(bps)
```

**分辨率推荐规则**:
- 4K (3840×2160): 需要 ≥20 Mbps
- 1080p (1920×1080): 需要 ≥5 Mbps
- 720p (1280×720): 需要 ≥2.5 Mbps
- 480p (854×480): 需要 ≥1 Mbps
- 360p (640×360): ≥0.5 Mbps

**画质评级标准**:
- ★★★★★ 优秀: 分辨率保持 ≥90% 且码率 ≥5 Mbps
- ★★★★☆ 良好: 分辨率保持 ≥50% 且码率 ≥2.5 Mbps
- ★★★☆☆ 一般: 压缩比 ≥30% 且码率 ≥1.5 Mbps
- ★★☆☆☆ 较差: 压缩比 ≥15% 或码率 ≥0.8 Mbps
- ★☆☆☆☆ 很差: 其他情况

## 二、实时颜色调整预览

### 功能特点

- **时间轴选择器**: 用户可以选择视频中任意时间点作为预览帧
- **滑块对比视图**: 通过拖动滑块实时对比调整前后的效果
- **实时预览**: 调整参数时自动更新预览（带防抖优化）
- **性能优化**: 帧缓存机制避免重复提取

### 使用方法

1. 在颜色调整页面加载视频
2. 使用时间轴选择器选择预览帧位置（默认为视频中间）
3. 调整亮度、对比度、饱和度等参数
4. 在对比视图中拖动滑块查看效果
5. 满意后点击"应用调整"处理整个视频

### 技术实现

#### 新增文件

- `fastv/Views/Components/ImageComparisonSlider.swift` - 滑块对比组件
  - 左右分屏显示
  - 可拖动的分割线
  - 支持点击定位
  - 原图/调整后标签

- `fastv/Views/Components/VideoTimelineSelector.swift` - 时间轴选择器
  - 可视化时间轴
  - 拖动选择时间点
  - 时间格式化显示
  - 支持点击跳转

- `fastv/Services/VideoFrameCache.swift` - 帧缓存管理器
  - Actor 并发安全
  - LRU 缓存策略
  - 最多缓存 20 帧
  - 自动清理机制

#### 修改文件

- `fastv/Services/VideoColorAdjuster.swift` - 添加帧提取和图片处理方法
  - `extractFrame()` - 提取视频帧
  - `applyColorAdjustmentToImage()` - 对图片应用颜色调整
  - `extractAndAdjustFrame()` - 提取并调整帧（带缓存）

- `fastv/Views/VideoTools/VideoColorAdjustmentView.swift` - 集成预览功能
  - 时间轴选择器集成
  - 对比预览视图
  - 防抖机制（300ms）
  - 缓存清理逻辑

### 性能优化

1. **防抖机制**: 滑块调整时延迟 300ms 后才更新预览，避免频繁调用 FFmpeg
2. **帧缓存**: 缓存已提取的原始帧，切换时间点时无需重复提取
3. **异步处理**: 所有图像处理在后台线程执行，不阻塞 UI
4. **智能清理**: 页面关闭时自动清理缓存，释放内存

### FFmpeg 命令示例

**提取单帧**:
```bash
ffmpeg -ss 00:02:15 -i input.mp4 -vframes 1 -q:v 2 output.jpg
```

**对图片应用颜色调整**:
```bash
ffmpeg -i input.jpg -vf "eq=brightness=0.1:contrast=1.2:saturation=1.3" output.jpg
```

## 四、用户体验流程

### 智能压缩向导流程

```
加载视频 → 开启智能向导 → 输入目标大小 → 查看推荐参数 → 应用/微调 → 开始压缩
```

### 颜色调整预览流程

```
加载视频 → 选择预览帧 → 调整参数 → 实时查看对比 → 应用到整个视频
```

## 五、技术亮点

1. **智能算法**: 基于视频特征和目标大小自动推荐最优参数
2. **实时反馈**: 用户调整参数时立即看到效果
3. **性能优化**: 防抖、缓存、异步处理确保流畅体验
4. **直观对比**: 滑块对比让效果一目了然
5. **灵活控制**: 既可使用推荐参数，也可手动微调

## 六、注意事项

1. 首次提取帧时可能需要几秒钟，后续切换参数会更快（得益于缓存）
2. 智能向导的推荐参数是基于经验值，实际效果可能因视频内容而异
3. 预览图片的颜色调整效果与最终视频效果完全一致（使用相同的 FFmpeg 滤镜）
4. 帧缓存最多保存 20 帧，超出后会自动清理最旧的帧

## 七、未来改进方向

2. 添加预设方案（如"高质量"、"平衡"、"小文件"等）
3. 支持实时视频预览（而非静态图片）
4. 添加直方图显示，更直观地查看颜色分布
5. 支持批量应用相同的调整参数到多个视频
