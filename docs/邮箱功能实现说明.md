# 邮箱功能历史说明（已归档）

邮箱是 v2.0.0 以前的实验产品线，当前主线已不包含邮箱数据模型、服务或界面，也不应再按旧方案恢复相关依赖。

自 v2.5.0-rc2 起，项目已经移除源码零引用的 GRDB.swift 和整个 CocoaPods 集成：

- 不再提供或维护邮箱数据库实现。
- 不再通过 `Podfile` 管理任何依赖。
- 不要为本项目执行 `pod install`。
- 当前工程直接使用 `fastv.xcodeproj` 构建；Sparkle 由 Swift Package Manager 管理，ONNX Runtime 与 Rime 使用仓库内受控二进制。

若未来重新立项邮箱功能，应重新完成数据安全、迁移、依赖审计与隐私评审，不沿用本归档文档中的历史实现。
