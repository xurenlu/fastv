# 妙打 - 界面重设计方案

## 一、核心卖点与典型场景

### 1.1 核心卖点提炼

#### 差异化优势
1. **精细的后续处理能力**
   - 常用词自动修正（学习用户习惯）
   - 自由水词快速修正（毫秒级响应）
   - AI智能优化（一键优化表达）

2. **多场景应用能力**
   - 语音输入法（基础功能）
   - 会议记录（自动检测会议软件，一键记录+AI总结）
   - 语音备忘录（快速生成笔记）
   - 实时字幕（视频播放时显示字幕+翻译）

3. **智能化联动**
   - 自动检测会议软件（腾讯会议、Zoom等）
   - 视频播放检测（自动启用字幕模式）
   - AI服务集成（总结、翻译、优化）

### 1.2 典型使用场景

#### 场景1：快速语音输入
- **用户行为**：在任何应用中按下快捷键，说话，松开快捷键
- **系统处理**：实时转文字 → 快速纠错 → 常错词修正 → 插入文本
- **核心价值**：毫秒级响应，无需等待

#### 场景2：会议记录
- **用户行为**：检测到腾讯会议运行 → 弹出提示 → 用户确认 → 开始记录
- **系统处理**：持续录音 → 实时转文字 → 会议结束后 → AI总结
- **核心价值**：自动检测，一键完成，智能总结

#### 场景3：语音备忘录
- **用户行为**：按下快捷键 → 说话 → 松开 → 自动保存为笔记
- **系统处理**：转文字 → 纠错 → 优化 → 保存到笔记库
- **核心价值**：快速记录，自动整理

#### 场景4：视频字幕
- **用户行为**：播放视频时自动检测 → 启用字幕模式
- **系统处理**：实时转文字 → 显示字幕 → 可选翻译
- **核心价值**：实时字幕，多语言支持

- **语音输入**：基础功能，快速输入

- **语音备忘录**：快速生成笔记
- **实时字幕**：视频播放时显示字幕

#### 第二层：快捷功能（常用操作）
- **常用词管理**：添加、编辑、删除常用词
- **水词修正**：启用/禁用，自定义水词列表

- **麦克风状态**：权限、占用情况
- **AI服务状态**：连接状态、响应时间
- **会议检测状态**：当前检测到的会议软件

### 2.3 数据展示优先级

1. **最高优先级**：场景卡片（用户主要操作入口）
2. **高优先级**：常用词管理、水词修正（核心差异化功能）
3. **中优先级**：实时状态、历史记录
4. **低优先级**：详细设置（移至设置页面）

## 四、关键交互流程

### 4.1 语音输入流程

```
用户按下快捷键
    ↓
显示波形窗口（实时音频可视化）
    ↓
开始录音
    ↓
用户说话
    ↓
用户松开快捷键
    ↓
停止录音 → 显示"转文字中"状态
    ↓
语音转文字（本地处理）
    ↓
快速纠错（毫秒级）
    ↓
常错词修正（如果启用）
    ↓
AI优化（如果按了Ctrl键）
    ↓
插入文本到当前输入框
    ↓
保存到历史记录
    ↓
隐藏波形窗口
```

### 4.2 会议记录流程

```
应用启动/后台运行
    ↓
定期检测运行中的应用（每5秒）
    ↓
检测到会议软件（腾讯会议、Zoom等）
    ↓
弹出提示弹窗："检测到腾讯会议，是否开始记录？"
    ↓
用户点击"开始记录"
    ↓
开始持续录音（不插入文本）
    ↓
实时转文字并显示在会议记录界面
    ↓
用户点击"结束记录"或检测到会议结束
    ↓
停止录音
    ↓
调用AI进行总结
    ↓
显示总结结果
    ↓
保存会议记录（包含原始文本和总结）
```

### 4.3 语音备忘录流程

```
用户点击"新建笔记"或按下快捷键
    ↓
弹出笔记创建界面
    ↓
用户按下快捷键开始录音
    ↓
显示波形窗口
    ↓
用户说话
    ↓
用户松开快捷键
    ↓
转文字 → 纠错 → 优化
    ↓
显示预览文本
    ↓
用户确认/编辑
    ↓
保存为笔记（带时间戳）
    ↓
添加到笔记列表
```

### 4.4 实时字幕流程

```
检测到视频播放（通过系统API）
    ↓
弹出提示："检测到视频播放，是否启用字幕？"
    ↓
用户确认启用
    ↓
开始持续录音
    ↓
实时转文字
    ↓
显示字幕窗口（悬浮在视频上方）
    ↓
可选：启用翻译
    ↓
调用AI翻译服务
    ↓
显示双语字幕
    ↓
视频播放结束或用户手动关闭
    ↓
停止录音和字幕显示
```

### 4.5 常用词管理流程

```
用户点击"常用词管理"
    ↓
显示常用词列表（在主界面快捷功能区）
    ↓
用户点击"添加"
    ↓
弹出添加对话框
    ↓
用户输入错误词和正确词
    ↓
点击"添加"
    ↓
保存到常用词库
    ↓
立即生效（下次语音输入时自动修正）
```

### 4.6 水词修正流程

```
用户点击"水词修正" → "自定义"
    ↓
显示水词列表（嗯、啊、那个、这个...）
    ↓
用户可以：
  - 添加新水词
  - 删除现有水词
  - 启用/禁用自动修正
    ↓
保存设置
    ↓
下次语音输入时自动去除水词
```

## 五、技术实现要点

### 5.1 会议软件检测
- 使用 `NSWorkspace.shared.runningApplications` 检测运行中的应用
- 匹配应用Bundle ID或进程名（腾讯会议、Zoom、Teams等）
- 定期轮询（每5秒）或使用通知机制

### 5.2 视频播放检测
- 检测全屏应用
- 检测视频播放器应用（QuickTime、VLC、浏览器等）
- 可能需要使用 Accessibility API 检测窗口状态

### 5.3 实时字幕窗口
- 创建悬浮窗口（类似波形窗口）
- 显示在视频上方，可拖拽位置
- 支持透明度调整

### 5.4 AI服务集成
- 总结功能：将会议记录发送给AI，生成摘要
- 翻译功能：实时翻译字幕文本
- 优化功能：优化语音转文字结果

## 六、界面设计原则

### 6.1 信息层次
1. **主要功能**：场景卡片（大、醒目）
2. **快捷功能**：常用词、水词（中等、易访问）
3. **状态信息**：实时状态栏（小、不干扰）

### 6.2 视觉引导
- 使用卡片式设计，清晰分隔不同功能
- 使用图标+文字，快速识别功能
- 使用状态指示器，清晰显示当前状态

### 6.3 交互反馈
- 按钮点击有视觉反馈
- 状态变化有动画过渡
- 操作结果有明确提示

### 6.4 macOS设计规范
- 使用系统标准控件
- 遵循macOS颜色和字体规范
- 支持深色模式
- 使用系统图标（SF Symbols）

## 八、总结

本次界面重设计的核心目标是：
1. **突出差异化功能**：将常用词、水词修正等核心功能前置到主界面
2. **多场景应用**：通过场景卡片展示不同的使用场景
