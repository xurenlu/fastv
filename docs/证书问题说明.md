# 证书问题说明

## 发现的问题

您下载的证书信息：
- **公司名称**: Beijing Alibaba information Technology Co., Ltd.
- **Team ID**: ZH2S7D6PL6
- **证书类型**: Developer ID Application

但项目配置的 Team ID：
- **Team ID**: W49B66SUW3

## 问题原因

证书的 Team ID 与项目配置不匹配，这会导致：
1. 无法使用该证书签名应用
2. 即使签名成功，签名验证也会失败
3. 应用无法正常运行

## 解决方案

### 方案 1：使用正确的证书（推荐）

如果您有自己的 Apple Developer 账号（Team ID: W49B66SUW3），需要：

1. **确认账号信息**
   - 访问：https://developer.apple.com/account
   - 确认您的 Team ID 是 W49B66SUW3

2. **申请正确的证书**
   - 使用您的账号申请 Developer ID Application 证书
   - 确保 Team ID 匹配

3. **下载并安装证书**
   - 下载后双击安装，或使用命令行安装

### 方案 2：如果这是公司证书

如果这个证书是公司提供的，需要：

1. **更新项目配置**
   - 修改 Xcode 项目中的 Team ID 为 ZH2S7D6PL6
   - 或使用 Xcode 选择正确的 Team

2. **检查私钥匹配**
   - Developer ID 证书需要匹配的私钥
   - 如果私钥不匹配，证书无法用于签名

## 检查证书和私钥匹配

运行以下命令检查：

```bash
# 检查证书信息
openssl x509 -inform DER -in developerID_application.cer -text -noout | grep -E "Subject:|Serial Number:"

# 检查 Keychain 中的证书和私钥
security find-certificate -a -c "Developer ID" -p | openssl x509 -text -noout | grep -E "Subject:"
security find-identity -v -p codesigning | grep "Developer ID"
```
