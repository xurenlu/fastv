# 应用专用密码设置指南

## 什么是应用专用密码？

应用专用密码（App-Specific Password）是 Google 为启用了两步验证的账号提供的一种特殊密码，用于允许第三方应用（如邮件客户端）访问您的 Gmail 账号。

**重要提示**：
- 如果您的 Gmail 账号**启用了两步验证**，必须使用应用专用密码
- 如果您的 Gmail 账号**未启用两步验证**，可以使用普通密码
- 应用专用密码是 16 位字符，不包含空格

## 如何生成 Gmail 应用专用密码

### 方法一：通过应用界面（推荐）

1. **打开邮箱账号管理**
   - 在应用主界面，点击工具栏的"账号管理"按钮

2. **添加或编辑 Gmail 账号**
   - 点击"添加账号"或选择现有 Gmail 账号点击"编辑"
   - 选择邮箱服务为"Gmail"

3. **点击提示链接**
   - 在密码输入框下方，您会看到橙色提示信息
   - 点击"在浏览器中设置 Gmail 应用专用密码"链接
   - 这会自动打开 Google 账号的应用专用密码设置页面

4. **生成密码**
   - 在浏览器中，选择"应用"为"邮件"
   - 选择"设备"为"Mac"（或其他设备类型）
   - 点击"生成"按钮
   - **复制生成的 16 位密码**（格式如：`abcd efgh ijkl mnop`）

5. **在应用中输入密码**
   - 返回应用
   - 在"密码"字段中粘贴刚才复制的密码
   - **注意**：粘贴时不需要手动删除空格，应用会自动处理
   - 点击"保存"

### 方法二：直接访问 Google 账号设置

1. **访问 Google 账号安全页面**
   - 打开浏览器，访问：https://myaccount.google.com/security
   - 或者直接访问：https://myaccount.google.com/apppasswords

2. **启用两步验证**（如果尚未启用）
   - 如果您的账号未启用两步验证，需要先启用
   - 在"安全"页面找到"两步验证"部分
   - 按照提示完成两步验证设置

3. **生成应用专用密码**
   - 在"安全"页面，找到"应用专用密码"部分
   - 点击"应用专用密码"
   - 如果提示输入密码，请输入您的 Google 账号密码
   - 选择"应用"：选择"邮件"
   - 选择"设备"：选择"Mac"（或"其他"并输入"妙打"）
   - 点击"生成"按钮

4. **复制密码**
   - Google 会显示一个 16 位的密码
   - **立即复制这个密码**（格式如：`abcd efgh ijkl mnop`）
   - ⚠️ **重要**：这个密码只会显示一次，关闭页面后无法再次查看
   - 如果忘记密码，需要删除并重新生成

5. **在应用中输入密码**
   - 打开应用
   - 进入"账号管理"
   - 添加或编辑 Gmail 账号
   - 在"密码"字段中粘贴应用专用密码
   - 点击"保存"

## 在应用中设置密码的详细步骤

### 添加新账号

1. 打开应用，点击"账号管理"
2. 点击"添加账号"按钮
3. 选择"邮箱服务"为"Gmail"
4. 输入您的 Gmail 邮箱地址
5. 输入显示名称（可选）
6. **在"密码"字段中输入应用专用密码**
   - 如果是新账号，必须输入密码
   - 可以直接粘贴，应用会自动处理空格
7. 点击"保存"

### 编辑现有账号

1. 打开应用，点击"账号管理"
2. 找到要编辑的 Gmail 账号
3. 点击账号右侧的"..."菜单
4. 选择"编辑"
5. **在"密码"字段中输入新的应用专用密码**
   - 如果留空，则不会修改已保存的密码
   - 如果要更新密码，请输入新的应用专用密码
6. 点击"保存"

## 常见问题

### Q1: 为什么需要应用专用密码？

**A:** Google 为了安全，要求启用了两步验证的账号必须使用应用专用密码来访问 IMAP/SMTP 服务。这样可以：
- 保护您的账号安全
- 允许您随时撤销特定应用的访问权限
- 避免在第三方应用中存储您的主密码

### Q2: 如何知道我的账号是否启用了两步验证？

**A:** 
1. 访问 https://myaccount.google.com/security
2. 查看"两步验证"部分
3. 如果显示"已开启"，则需要使用应用专用密码
4. 如果显示"已关闭"，可以使用普通密码

### Q3: 应用专用密码可以重复使用吗？

**A:** 可以。一旦生成，应用专用密码可以一直使用，直到您手动删除它。您可以：
- 在多个应用中使用同一个应用专用密码
- 或者为每个应用生成不同的密码（推荐，便于管理）

### Q4: 忘记应用专用密码怎么办？

**A:** 
1. 访问 https://myaccount.google.com/apppasswords
2. 找到之前生成的密码（会显示应用和设备名称）
3. 点击"删除"按钮删除旧密码
4. 重新生成新的应用专用密码
5. 在应用中更新密码

### Q5: 密码输入框显示"密码（留空则不修改）"是什么意思？

**A:** 这是编辑现有账号时的提示。意思是：
- 如果留空：不会修改已保存的密码，继续使用旧密码
- 如果输入新密码：会更新为新的密码

### Q6: 粘贴密码时需要注意什么？

**A:** 
- 应用会自动处理空格，所以可以直接粘贴
- 确保复制了完整的 16 位密码
- 密码格式通常是：`abcd efgh ijkl mnop`（带空格）或 `abcdefghijklmnop`（无空格）
- 两种格式都可以，应用会自动处理

### Q7: 测试连接时提示"密码不能为空"怎么办？

**A:** 
- 如果是新账号：确保在"密码"字段中输入了应用专用密码
- 如果是编辑账号：要么输入新密码，要么确保之前已经保存过密码

### Q8: 连接测试失败，提示认证错误怎么办？

**A:** 
1. **检查密码是否正确**
   - 确保使用的是应用专用密码，不是普通密码
   - 确保密码没有多余的空格或字符

2. **检查两步验证**
   - 确认账号已启用两步验证
   - 如果未启用，需要先启用两步验证

3. **重新生成密码**
   - 删除旧的应用专用密码
   - 生成新的应用专用密码
   - 在应用中更新密码

4. **检查 IMAP 设置**
   - 确认 Gmail 已启用 IMAP
   - 访问 Gmail 设置 → 转发和 POP/IMAP → 启用 IMAP

### Q9: 可以为一个账号生成多个应用专用密码吗？

**A:** 可以。您可以：
- 为不同的应用生成不同的密码
- 为不同的设备生成不同的密码
- 这样便于管理和撤销特定应用的访问权限

### Q10: 应用专用密码安全吗？

**A:** 是的，应用专用密码是安全的：
- 只能用于访问 IMAP/SMTP 服务，不能用于登录 Google 账号
- 可以随时撤销，不影响其他应用
- 不会暴露您的主密码
- 建议定期更换

## 其他邮箱服务

### Outlook/Hotmail

- **通常不需要应用专用密码**
- 使用您的 Microsoft 账号密码即可
- 如果启用了两步验证，可能需要应用专用密码

### 企业邮箱

- **通常不需要应用专用密码**
- 使用您的企业邮箱密码即可
- 具体取决于企业邮箱的安全策略

## 安全建议

1. **定期更换密码**：建议每 3-6 个月更换一次应用专用密码
2. **不要分享密码**：应用专用密码应该保密，不要分享给他人
3. **及时删除不用的密码**：如果不再使用某个应用，及时删除对应的应用专用密码
4. **使用不同的密码**：为不同的应用生成不同的密码，便于管理
