# DeepSeek-R1:1.5B 完整使用指南（小白版）

## 🎯 目标

让 DeepSeek-R1:1.5B 运行得更快，同时保持文本优化的质量。

## 📋 方案对比

### 方案 1：优化后的 Ollama（推荐，最简单）⭐

**优点：**
- ✅ 已经配置好了，直接可用
- ✅ 不需要下载新模型
- ✅ 速度已优化（从 7.64s 降到 3.25s）
- ✅ 轻微修改能力最好（61.3分）

**使用方法：**
1. 确保 Ollama 服务正在运行
2. 在 fastv 中设置：
   - API 端点：`http://127.0.0.1:11434` 或你的公网地址
   - 模型：`deepseek-r1:1.5b`
   - 超时时间：5-8 秒

**当前性能：**
- 平均响应时间：3.25秒
- 轻微修改分数：61.3/100
- 优秀测试数：5/8

### 方案 2：llama.cpp + HTTP API（更快，但需要配置）

**优点：**
- ✅ 可能更快（预期 1.5-2.5秒）
- ✅ 无 thinking 模式延迟
- ✅ 更精确的控制

**缺点：**
- ⚠️ 需要下载 GGUF 格式模型（可能不容易找到）
- ⚠️ 需要手动配置

**使用方法：**

#### 步骤 1：安装依赖

```bash
# 安装 Python Flask（如果还没有）
pip3 install flask flask-cors
```

#### 步骤 2：下载模型（可选）

```bash
# 运行下载脚本
bash download_deepseek_model.sh
```

**注意：** 如果找不到 GGUF 模型，可以跳过这一步，直接使用方案 1。

#### 步骤 3：启动 HTTP API 服务

```bash
# 启动服务
bash start_llama_api.sh
```

服务会在 `http://127.0.0.1:11435` 启动

#### 步骤 4：在 fastv 中使用

- API 端点：`http://127.0.0.1:11435`
- 模型：任意（API 会自动使用配置的模型）
- 超时时间：3-5 秒

## 🚀 快速开始（推荐方案 1）

### 1. 测试当前优化配置


### 2. 在 fastv 中配置

1. 打开 fastv 应用
2. 进入设置 → AI 文本优化
3. 设置：
   - ✅ 启用 AI 文本优化

   - 模型：`deepseek-r1:1.5b`
   - 超时时间：5 秒
4. 点击"测试连接"
5. 点击"测试文本优化"

### 3. 开始使用

按下语音输入快捷键（默认 ⌥V），说话，松开，等待优化后的文本自动插入。

## 🔧 故障排查

### 问题 1：连接失败

**解决：**
- 检查 Ollama 服务是否运行：`ollama serve`
- 检查 API 端点是否正确
- 检查网络连接

### 问题 2：响应太慢

**解决：**
- 增加超时时间到 8-10 秒
- 检查网络延迟
- 考虑使用本地 Ollama（如果可能）

### 问题 3：输出质量不好

**解决：**
- 检查系统提示词是否正确
- 尝试调整 temperature（0.1-0.3）
- 使用测试脚本验证效果
