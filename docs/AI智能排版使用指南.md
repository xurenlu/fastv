# AI智能排版使用指南

## 功能介绍

AI智能排版是一个强大的邮件正文美化功能，通过AI技术优化HTML格式邮件的排版布局，使邮件更加美观易读，同时保持内容的完整性和原意。

## 如何使用

### 1. 查看邮件

打开任何一封HTML格式的邮件（包含富文本内容的邮件），在邮件详情页面顶部会看到操作按钮栏。

### 2. 找到AI排版按钮

在操作按钮栏的右侧，您会看到以下按钮从左到右依次排列：

```
[回复] [全部回复] [转发]    [AI排版✨] [星标⭐] [垃圾邮件⚠️] [删除🗑️]
```

- **AI排版按钮图标**：`✨` 矩形堆叠图标
- **位置**：位于星标按钮之前
- **显示条件**：仅对HTML格式邮件显示

### 3. 点击优化

**首次点击**：
- 图标从线框样式变为填充样式
- 图标颜色变为紫色
- 显示短暂的加载动画
- AI开始分析和优化HTML结构

**再次点击**：
- 恢复原始排版
- 图标变回线框样式（灰色）

### 4. 查看效果

优化完成后，邮件正文会自动更新显示：
- 更清晰的段落结构
- 更合理的标题层级
- 更美观的列表格式
- 移除了冗余的表格布局
- 统一的样式风格

## 优化示例

### 优化前（混乱的HTML）

```html
<table><tr><td>
    <font size="3" color="black">
        您好，<br><br>
        &nbsp;&nbsp;&nbsp;&nbsp;感谢您的来信。<br>
        &nbsp;&nbsp;&nbsp;&nbsp;我们已经收到您的反馈。<br><br>
        此致<br>
        客服团队
    </font>
</td></tr></table>
```

### 优化后（语义化HTML）

```html
<p>您好，</p>

<p>感谢您的来信。我们已经收到您的反馈。</p>

<p>此致<br>
客服团队</p>
```

## 优化范围

### ✅ AI会优化

1. **HTML结构**
   - 将 `<table>` 布局改为 `<p>` 段落
   - 添加合适的标题标签 `<h1>-<h6>`
   - 使用列表标签 `<ul>` `<ol>` `<li>`
   - 引用内容用 `<blockquote>`

2. **格式清理**
   - 移除内联样式（style属性）
   - 删除 `&nbsp;` HTML实体
   - 移除多余的嵌套标签
   - 统一空格和换行

3. **内容增强**
   - 合理分段
   - 长段落断句
   - 重要内容加粗或斜体
   - 代码格式化

### ❌ AI不会改变

1. **原始内容**
   - 文字内容
   - 链接地址
   - 图片URL
   - 附件信息

2. **基本语义**
   - 段落含义
   - 列表顺序
   - 引用关系
   - 强调重点

## 技术细节

### 内置CSS样式

软件会自动为邮件正文添加以下样式，AI优化时会考虑这些样式：

```css
/* 字体 */
font-family: -apple-system, "PingFang SC", sans-serif;
font-size: 16px;
line-height: 1.6;

/* 颜色 */
color: #1d1d1f;           /* 主文字 */
a { color: #007AFF; }      /* 链接 */

/* 标题 */
h1, h2, h3 { 
    font-weight: 600;
}

/* 图片 */
img { 
    border-radius: 8px; 
}

/* 代码 */
code, pre { 
    background-color: #f5f5f7; 
}
```

### 优化策略

AI会根据以下原则进行优化：

1. **保持内容完整性**：不删减任何信息
2. **语义化优先**：使用正确的HTML标签
3. **简洁明了**：移除冗余代码
4. **视觉友好**：改善阅读体验
5. **响应式兼容**：适配不同窗口大小

## 使用建议

### 适合优化的邮件

✅ **营销邮件**
- 通常包含复杂的表格布局
- 大量内联样式
- 优化后可读性大幅提升

✅ **富文本邮件**
- 使用Word或其他编辑器编写
- 粘贴后产生冗余HTML
- 优化后更加清爽

✅ **长文邮件**
- 多段落内容
- 需要更好的结构
- 优化后层次更清晰

### 不建议优化的邮件

❌ **纯文本邮件**
- 没有HTML标签
- 功能不可用

❌ **简单邮件**
- 已经排版良好
- 无需优化

❌ **交互式邮件**
- 包含表单
- 包含JavaScript
- 可能影响功能

## 常见问题

### Q1: 优化会改变邮件内容吗？

**A:** 不会。AI只会优化HTML结构和排版，不会改变文字内容、链接、图片等信息。

### Q2: 优化后可以恢复原样吗？

**A:** 可以。再次点击AI排版按钮即可恢复原始版本，可以随时在两个版本间切换。

### Q3: 优化需要多长时间？

**A:** 通常2-5秒，具体取决于邮件复杂度和网络状况。优化过程中会显示加载动画。

### Q4: 优化失败怎么办？

**A:** 如果优化失败，会显示错误提示，邮件保持原始状态不变。可以稍后重试。

### Q5: 优化结果会保存吗？

**A:** 优化结果在当前会话中缓存，切换到其他邮件再回来仍然保持优化状态。关闭应用后需要重新优化。

### Q6: 为什么有些邮件没有AI排版按钮？

**A:** 只有HTML格式的邮件才显示此按钮。纯文本邮件无法优化排版。

### Q7: 优化会影响图片显示吗？

**A:** 不会。图片显示由独立的"显示图片"功能控制，AI排版不影响图片。

### Q8: 可以批量优化多封邮件吗？

**A:** 当前版本需要逐封优化。未来版本可能会支持批量操作。
