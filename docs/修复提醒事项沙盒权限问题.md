# 修复提醒事项沙盒权限问题

## 问题描述

错误信息：
```
Received error from calaccessd connection: Error Domain=NSCocoaErrorDomain Code=4099 
"The connection to service named com.apple.CalendarAgent was invalidated: 
Connection init failed at lookup with error 159 - Sandbox restriction."
```

## 原因分析

应用启用了 **App Sandbox**，但缺少访问日历/提醒事项服务的权限。EventKit 需要连接到系统的 `CalendarAgent` 服务，但沙盒限制了这种连接。

## 解决方案

### ✅ 已添加的 Entitlements

在 `fastv/fastv.entitlements` 中添加了以下权限：

1. **提醒事项访问权限**
   ```xml
   <key>com.apple.security.personal-information.reminders</key>
   <true/>
   ```

2. **日历访问权限**
   ```xml
   <key>com.apple.security.personal-information.calendars</key>
   <true/>
   ```

3. **地址簿访问权限**
   ```xml
   <key>com.apple.security.personal-information.addressbook</key>
   <true/>
   ```

### 为什么需要这三个权限？

- **reminders**: 直接访问提醒事项数据
- **calendars**: EventKit 框架可能需要访问日历服务
- **addressbook**: EventKit 在某些情况下可能需要访问地址簿（用于联系人关联）

## 下一步操作

### 1. 清理并重新构建

```bash
# 清理 Xcode 的 DerivedData
rm -rf ~/Library/Developer/Xcode/DerivedData/fastv-*

# 在 Xcode 中：
# 1. Product > Clean Build Folder (Shift+Command+K)
# 2. Product > Build (Command+B)
# 3. Product > Run (Command+R)
```

### 2. 重置权限缓存

```bash
# 重置提醒事项权限
tccutil reset Reminders com.wxside.typecho

# 重置日历权限（如果需要）
tccutil reset Calendar com.wxside.typecho

# 重置地址簿权限（如果需要）
tccutil reset AddressBook com.wxside.typecho
```

### 3. 测试权限请求

1. 运行应用
2. 尝试使用提醒事项同步功能
3. 应该会弹出权限请求对话框
4. 查看控制台输出，确认权限状态

## 如果还是不行

### 方案 1：检查 Info.plist 配置

确保 `Info.plist` 中有正确的权限说明：

```xml
<key>NSRemindersFullAccessUsageDescription</key>
<string>妙打 需要访问您的提醒事项以同步待办事项到 AI Todo 功能中。应用只会读取未完成的提醒事项，不会修改或删除您的提醒事项。</string>
```

### 方案 2：临时禁用沙盒测试（仅用于调试）

如果添加 entitlements 后还是不行，可以临时禁用沙盒来测试：

1. 在 Xcode 中，选择 Target
2. 进入 "Signing & Capabilities"
3. 取消勾选 "App Sandbox"
4. 运行测试
5. 如果这样可以工作，说明是沙盒配置问题

**注意**：这只是用于调试，发布到 App Store 时必须启用沙盒。

### 方案 3：检查系统版本

确保你的 macOS 版本支持这些权限：
- macOS 10.14+ 支持提醒事项权限
- macOS 14.0+ 需要使用 `requestFullAccessToReminders` 而不是 `requestAccess`

## 验证修复

运行应用后，控制台应该显示：

```

```

而不是之前的错误信息。
