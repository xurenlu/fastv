# 视频压缩向导与颜色调整预览 - 快速开始

## 一、智能压缩向导

### 快速使用

1. **打开视频工具**
   - 启动 fastv 应用
   - 选择"视频工具" → "压缩调整"

2. **加载视频**
   - 拖拽视频文件到预览区域
   - 或点击选择视频文件

3. **开启智能向导**
   - 勾选"使用智能向导"开关
   - 系统会自动加载视频信息

4. **设置目标大小**
   - 输入期望的文件大小，例如 `500`
   - 选择单位：MB 或 GB
   - 系统会立即显示推荐参数

5. **查看推荐结果**
   ```
   📊 智能推荐参数
   ├─ 推荐分辨率: 1080p
   ├─ 推荐帧率: 30 fps
   ├─ 推荐码率: 3.5 Mbps
   ├─ 预估压缩比: 65%
   └─ 画质评级: ★★★★☆ (良好)
   ```

6. **应用参数**
   - 点击"应用推荐参数"按钮
   - 或在"手动调整"区域微调参数

7. **开始压缩**
   - 点击"开始压缩"按钮
   - 选择保存位置
   - 等待压缩完成

## 二、实时颜色调整预览

### 快速使用

1. **打开颜色调整**
   - 启动 fastv 应用
   - 选择"视频工具" → "颜色调整"

2. **加载视频**
   - 拖拽视频文件到预览区域
   - 系统会自动提取中间帧作为预览

3. **选择预览帧**
   - 使用时间轴选择器选择要预览的时间点
   - 拖动滑块或点击时间轴
   - 系统会自动提取该帧

4. **调整颜色参数**
   - 拖动"亮度"滑块调整明暗
   - 拖动"对比度"滑块调整对比
   - 拖动"饱和度"滑块调整色彩浓度
   - 拖动"色温"滑块调整冷暖色调

5. **查看对比效果**
   - 在对比视图中拖动中间的分割线
   - 左侧显示原图，右侧显示调整后效果
   - 实时对比调整效果

6. **应用到视频**
   - 满意后点击"应用调整"按钮
   - 选择保存位置
   - 等待处理完成

### 操作技巧

#### 技巧 1: 快速对比

- 将滑块拖到最左边 → 只看原图
- 将滑块拖到最右边 → 只看调整后
- 来回拖动 → 快速对比差异

#### 技巧 2: 选择合适的预览帧

- 选择画面有代表性的场景
- 避免选择全黑或全白的画面
- 可以多次切换时间点查看不同场景的效果

#### 技巧 3: 参数调整建议

**修正曝光不足**:
```
亮度: +0.2 到 +0.4
对比度: 1.1 到 1.2
```

**修正过曝**:
```
亮度: -0.2 到 -0.3
对比度: 0.9 到 1.0
```

**增强色彩**:
```
饱和度: 1.3 到 1.5
对比度: 1.1 到 1.2
```

**营造冷色调**:
```
色温: 8000K 到 10000K
```

**营造暖色调**:
```
色温: 3000K 到 4500K
```

#### 场景 1: 修正室内视频偏暗

## 三、常见问题

### Q1: 为什么预览生成需要几秒钟？

**A**: 首次提取帧需要调用 FFmpeg 处理视频，需要一些时间。但得益于缓存机制，后续调整参数时会更快。

### Q2: 推荐的参数不满意怎么办？

**A**: 可以在"手动调整"区域自由修改分辨率、帧率、CRF 等参数，系统推荐只是一个参考。

### Q3: 预览效果和最终视频一致吗？

**A**: 是的，预览使用的是与最终视频处理相同的 FFmpeg 滤镜，效果完全一致。

### Q4: 可以同时调整多个参数吗？

**A**: 可以，所有参数都是实时生效的，调整任何参数都会自动更新预览。

### Q5: 如何重置所有调整？

**A**: 将所有滑块恢复到默认值：
- 亮度: 0.0
- 对比度: 1.0
- 饱和度: 1.0
- 色温: 点击"重置"按钮

## 四、性能说明

### 智能压缩向导

- **计算速度**: 毫秒级，即时显示推荐结果
- **内存占用**: 极小，只需视频元数据
- **适用范围**: 支持所有视频格式和分辨率

### 颜色调整预览

- **首次提取**: 2-5 秒（取决于视频大小）
- **后续调整**: 0.5-2 秒（得益于防抖和缓存）
- **内存占用**: 约 20-50MB（缓存 20 帧）
- **清理机制**: 页面关闭时自动清理

## 六、最佳实践

1. **压缩前先预估**: 使用智能向导了解不同目标大小对应的画质
2. **选择关键帧**: 颜色调整时选择有代表性的场景作为预览
3. **参数适度**: 避免过度调整参数，保持画面自然
4. **多次尝试**: 可以尝试不同的参数组合，找到最佳效果
5. **保存原文件**: 处理前务必备份原始视频文件
