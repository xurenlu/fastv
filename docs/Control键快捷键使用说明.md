# Control键快捷键使用说明

## 功能概述

现在你可以使用**单独的左Control键**作为语音输入的快捷键了！这是一个非常好的选择，因为：

✅ **不容易冲突**：Control键单独使用时很少与其他应用冲突  
✅ **智能过滤**：如果同时按了其他键（如Ctrl+C），不会触发录音  
✅ **使用方便**：Control键位置好找，按起来很顺手  
✅ **响应迅速**：松开键后立即开始转录

## 使用方法

### 1. 设置快捷键

1. 打开应用，进入"设置"
2. 找到"语音输入法"部分
3. 启用"启用语音输入法"开关
4. 在"全局快捷键"区域，点击"点击录制快捷键"按钮
5. **单独按下左Control键**（不要按其他键）
6. 系统会捕获并显示"左Control"

### 2. 开始使用

**正常录音流程**：
1. 单独按下左Control键
2. 等待约50ms后，右上角（或你设置的位置）会出现悬浮条
3. 开始说话，悬浮条会显示音量波形
4. 松开Control键
5. 悬浮条变为转录状态（显示旋转图标）
6. 转录完成后，文字自动插入到当前输入框
7. 悬浮条自动消失

**不会触发录音的情况**：
- 按住Control键的同时按了其他键（如Ctrl+C、Ctrl+V等）
- 先按了其他键，再按Control键
- 按住Control键后，在松开前按了其他键

## 工作原理

### 技术实现

1. **监听flagsChanged事件**：Control键作为修饰键，通过`flagsChanged`事件监听
2. **延迟确认机制**：按下Control键后等待50ms，确认没有其他键按下才触发录音
3. **组合键过滤**：如果检测到其他键按下，立即取消录音触发
4. **释放检测**：松开Control键时，只有在没有按其他键的情况下才触发转录

### 代码逻辑

```swift
// 伪代码示例
按下Control键 {
    if (只有Control键，没有其他修饰键) {
        等待50ms
        if (期间没有按其他键) {
            触发录音
        }
    }
}

按下其他键 {
    if (Control键正在按下) {
        标记"按了其他键"
        取消录音触发
    }
}

松开Control键 {
    if (没有按其他键) {
        触发转录
    } else {
        静默取消（不触发转录）
    }
}
```

## 测试场景

### ✅ 应该触发录音的场景

1. **单独按下Control键**
   - 操作：按下Control → 说话 → 松开Control
   - 结果：✅ 录音并转录

2. **快速按下松开**
   - 操作：快速按下并松开Control键
   - 结果：✅ 录音（虽然时间很短）

3. **长时间按住**
   - 操作：按住Control键10秒 → 说话 → 松开
   - 结果：✅ 录音并转录

### ❌ 不应该触发录音的场景

1. **Ctrl+C（复制）**
   - 操作：按住Control → 按C → 松开C → 松开Control
   - 结果：❌ 不录音，执行复制操作

2. **Ctrl+V（粘贴）**
   - 操作：按住Control → 按V → 松开V → 松开Control
   - 结果：❌ 不录音，执行粘贴操作

3. **Ctrl+Shift+任意键**
   - 操作：按住Control → 按Shift → 按其他键
   - 结果：❌ 不录音

4. **先按其他键再按Control**
   - 操作：按住A → 按Control → 松开A → 松开Control
   - 结果：❌ 不录音（因为Control不是单独按下的）

5. **按住Control后按其他键**
   - 操作：按住Control → 等待1秒 → 按A → 松开A → 松开Control
   - 结果：❌ 不录音（检测到按了其他键）

## 常见问题

### Q1: 为什么按Control键没有反应？

**可能原因**：
1. 没有授予辅助功能权限
   - 解决：系统设置 > 隐私与安全性 > 辅助功能 > 勾选fastv
2. 没有授予麦克风权限
   - 解决：系统设置 > 隐私与安全性 > 麦克风 > 勾选fastv
3. 同时按了其他键
   - 解决：确保只按Control键，不要按其他键

### Q2: 按Control键后悬浮条出现了，但没有录音？

**可能原因**：
1. 麦克风被其他应用占用（如闪电说）
   - 解决：关闭其他语音输入应用
2. 麦克风硬件问题
   - 解决：检查系统设置中的麦克风是否正常工作

### Q3: 按Control键触发了录音，但我想取消怎么办？

**解决方法**：
- 在按住Control键的时候，按任意其他键（如A、B、C等）
- 这样松开Control键时就不会触发转录了

### Q4: 我习惯用Ctrl+C、Ctrl+V，会不会冲突？

**不会冲突**！
- 系统会智能检测是否按了其他键
- 只有**单独按Control键**才会触发录音
- Ctrl+C、Ctrl+V等组合键不会触发录音，正常执行原有功能

### Q5: 左Control和右Control有区别吗？

**目前只支持左Control键**：
- 代码中监听的是左Control键
- 右Control键不会触发录音
- 如果需要支持右Control，可以后续扩展

### Q6: 能不能改成"按下就录音，不用等50ms"？

**不建议**：
- 50ms的延迟是为了确认没有其他键按下
- 如果立即触发，可能会误触发（比如你想按Ctrl+C，但刚按下Control就开始录音了）
- 50ms非常短，人类几乎感觉不到延迟
