# 正确的安装和授权步骤

## 🎯 问题原因

从Xcode直接运行的应用（Debug构建）位于临时目录：
```
/Users/rocky/Library/Developer/Xcode/DerivedData/fastv-bsagblddbizlhxceqjtyzxtsgyzo/Build/Products/Debug/fastv.app
```

**系统设置中看不到这个路径的应用**，所以无法手动授权！

## ✅ 解决方案

### 已完成的操作 ✅

1. **已将应用复制到 /Applications 目录**
2. **已重置麦克风权限**

### 现在请按以下步骤操作

#### 步骤1：从Applications启动应用

**方法A：使用Finder**
1. 打开Finder
2. 进入"应用程序"（Applications）文件夹
3. 找到"fastv"
4. 双击运行

**方法B：使用命令行**
```bash
open /Applications/fastv.app
```

**方法C：使用Spotlight**
1. 按 Command + Space
2. 输入 "fastv"
3. 按回车运行

#### 步骤2：观察权限对话框

应用启动后，**应该会弹出系统权限对话框**：

```
┌─────────────────────────────────────────┐
│  "fastv" 想要访问您的麦克风              │
│                                         │
│  FastV 需要访问您的麦克风以进行语音      │
│  输入和语音转文字功能。                  │
│                                         │
│              [不允许]  [允许]            │
└─────────────────────────────────────────┘
```

**重要**：
- 对话框可能在后台，检查所有窗口
- 第一次可能需要等几秒钟
- 如果没看到，检查屏幕顶部的菜单栏

#### 步骤3：点击"允许"

点击对话框中的**"允许"**按钮。

#### 步骤4：验证权限

1. 打开"系统设置"
2. 进入"隐私与安全性" → "麦克风"
3. **现在应该能看到 fastv 了！**
4. 确保它被勾选

#### 步骤5：测试语音输入

1. 确保应用正在运行
2. 进入"设置" → "语音输入法"
3. 确保已启用并设置快捷键为"左Control"
4. 按下Control键
5. 应该看到波形窗口
6. 说话测试
7. 松开Control键
8. 等待转录

## 🔧 如果还是不行

### 检查1：确认应用位置

```bash
ls -la /Applications/fastv.app
```

应该显示应用存在。

### 检查2：确认Bundle ID

```bash
/usr/libexec/PlistBuddy -c "Print CFBundleIdentifier" /Applications/fastv.app/Contents/Info.plist
```

应该显示：`com.wxside.fastv`

### 检查3：手动添加权限

如果对话框还是不弹出：

1. 打开"系统设置"
2. "隐私与安全性" → "麦克风"
3. 点击左下角的锁图标解锁
4. 点击 + 号
5. 导航到 `/Applications`
6. 选择 `fastv.app`
7. 点击"打开"
8. 确保勾选

### 检查4：查看权限数据库

```bash
sqlite3 ~/Library/Application\ Support/com.apple.TCC/TCC.db "SELECT client, allowed, prompt_count FROM access WHERE service='kTCCServiceMicrophone' AND client LIKE '%fastv%';"
```

应该看到：
- `client`: com.wxside.fastv
- `allowed`: 1（如果已授权）
- `prompt_count`: 请求次数

## 🎯 方法2：Archive打包（更正式）

如果你想要更正式的安装方式：

### 步骤1：Archive

1. 在Xcode中选择菜单：Product → Archive
2. 等待编译完成
3. 在Organizer窗口中选择刚才的Archive
4. 点击"Distribute App"
5. 选择"Copy App"
6. 选择保存位置
7. 将生成的.app复制到 /Applications

### 步骤2：签名（如果需要）

如果遇到签名问题：

```bash
codesign --force --deep --sign - /Applications/fastv.app
```

## 💡 重要提示

### 开发时的建议

1. **开发调试**：从Xcode运行（快速迭代）
2. **测试权限**：复制到/Applications（测试系统集成）

### 权限相关

- **每次修改Info.plist后**，需要重新复制到/Applications
- **每次更改Bundle ID后**，需要重置权限
- **从Xcode运行的应用**，权限可能不稳定

### 快捷键相关

- **辅助功能权限**：在"系统设置 > 隐私与安全性 > 辅助功能"中授权
- **麦克风权限**：在"系统设置 > 隐私与安全性 > 麦克风"中授权
- **两个权限都需要**才能正常使用语音输入
