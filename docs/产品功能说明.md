# 产品功能说明

## 妙打 - 智能语音输入法（当前主线）

妙打是面向 macOS 的语音转文字输入工具，并集成 **IMAP 邮箱** 客户端。数据以本地处理为主，兼顾效率与隐私。

> **说明**：下文若仍出现「会议记录」「AI Chat」「实时字幕」等表述，多为历史版本或扩展方向；**当前默认主界面仅包含「语音输入」与「邮箱」**。更完整、与代码同步的概览见仓库根目录 [README.md](../README.md)。

### 当前核心能力

#### 1. 语音输入

- 按住全局快捷键（默认 FN）说话，松开后将语音转为文字并插入当前输入框
- 多语言识别（中文、英文、日文、韩文、粤语等）
- 智能分段、快/准双路径与可选 AI 优化（需在设置中配置 AI 服务）
- 常用词与水词等快速纠错（可在设置中管理）

#### 2. 邮箱

- 多账户 IMAP、文件夹、阅读与撰写邮件
- 详见 [邮箱功能实现说明.md](邮箱功能实现说明.md) 及设置中的邮箱配置

#### 3. 设置与扩展

- **快速配置 / AI 与模型 / 邮箱 / 数据与其他**：语音相关选项、可选 AI、邮箱账户与数据项

### 技术优势

- 本地 ONNX 推理（SenseVoice）与 Kaldi 特征提取
- 可选 STT HTTP/WebSocket API（`stt-api/`）对外暴露转写能力
