# MicroApp 窗口管理修复说明

## 问题描述

在查看某个节点的测速历史时，可能出现以下问题：
1. 测速历史窗口完全打不开
2. 窗口打开了但没有内容（显示空白）
3. 窗口无法关闭，没有关闭按钮

## 问题原因

MicroApp 内部可能通过 JavaScript 创建模态窗口（使用固定定位的 div 元素），但这些窗口可能：
- 缺少关闭按钮
- 没有错误处理机制
- 内容加载失败时没有提示
- 无法通过键盘快捷键关闭

## 解决方案

在 `MicroAppHostView.swift` 中添加了窗口管理器（WindowManager），自动为所有模态窗口添加关闭机制和错误处理。

### 主要功能

1. **自动检测模态窗口**
   - 检测所有固定定位或绝对定位的高 z-index 元素
   - 识别覆盖大部分视口的窗口（覆盖率 > 50%）

2. **自动添加关闭按钮**
   - 在每个模态窗口右上角添加关闭按钮（×）
   - 关闭按钮有悬停效果，易于识别
   - 支持点击关闭

3. **键盘快捷键支持**
   - 按 `ESC` 键可以关闭当前活动的模态窗口

4. **超时保护**
   - 如果窗口在 15 秒内没有加载任何内容，自动关闭
   - 防止空白窗口一直显示

5. **内容监控**
   - 监听窗口内容变化
   - 如果内容加载完成，自动取消超时保护

6. **自动扫描**
   - 使用 MutationObserver 监听 DOM 变化
   - 定期扫描（每 2 秒）确保不会遗漏新创建的窗口
   - 点击事件后多次扫描，确保捕获异步创建的窗口

## 技术实现

### 窗口检测逻辑

```javascript
isModalWindow: function(element) {
    // 检查是否是固定定位或绝对定位
    // 检查 z-index 是否足够高（> 100）
    // 检查是否覆盖了大部分视口（> 50%）
}
```

### 关闭按钮样式

- 位置：右上角（top: 12px, right: 12px）
- 样式：半透明黑色背景，白色 × 符号
- 悬停效果：红色背景，放大效果

### 关闭机制

1. 点击关闭按钮
2. 按 ESC 键
3. 超时自动关闭（15 秒无内容）
4. 触发 `close` 事件（如果应用监听）

## 使用说明

### 对于 MicroApp 开发者

窗口管理器会自动工作，无需额外配置。但建议：

1. **使用标准的模态窗口模式**
   ```html
   <div class="modal" style="position: fixed; z-index: 1000;">
       <!-- 内容 -->
   </div>
   ```

2. **监听关闭事件**（可选）
   ```javascript
   modalElement.addEventListener('close', function(e) {
       // 可以调用 e.preventDefault() 阻止关闭
       // 执行清理操作
   });
   ```

3. **确保窗口有内容**
   - 如果窗口内容需要异步加载，确保在 15 秒内显示内容
   - 否则窗口会被自动关闭

### 对于用户

- 所有模态窗口都会自动显示关闭按钮（右上角）
- 可以点击关闭按钮或按 ESC 键关闭窗口
- 如果窗口长时间空白，会自动关闭

## 调试

窗口管理器暴露到全局对象，可以在浏览器控制台中调试：

```javascript
// 查看所有管理的窗口
window.__microappWindowManager.managedWindows

// 手动扫描窗口
window.__microappWindowManager.scanAndManageWindows()

// 手动关闭窗口
window.__microappWindowManager.closeWindow(element)
```

## 注意事项

1. 窗口管理器只管理覆盖大部分视口的模态窗口
2. 小型的弹出提示不会被管理（避免干扰正常功能）
3. 如果应用需要阻止自动关闭，可以监听 `close` 事件并调用 `preventDefault()`
4. 超时时间设置为 15 秒，可以根据需要调整
