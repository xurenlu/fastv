# 权限配置说明

FastV 应用需要以下系统权限才能正常使用语音输入功能：

## ✅ 已配置的权限

权限配置已自动添加到项目设置中，无需手动配置。

### 1. 麦克风权限 (NSMicrophoneUsageDescription)
- **用途**: 录制语音输入
- **配置状态**: ✅ 已配置
- **配置位置**: `fastv.xcodeproj/project.pbxproj` (INFOPLIST_KEY_NSMicrophoneUsageDescription)
- **说明**: 首次使用时会自动弹出权限请求对话框

### 2. 辅助功能权限 (Accessibility / NSAppleEventsUsageDescription)
- **用途**: 
  - 监听全局快捷键（用于在任何应用中触发语音输入）
  - 模拟键盘输入（将识别文本自动插入到当前输入框）
  - 访问剪贴板并执行粘贴操作
- **配置状态**: ✅ 已配置
- **配置位置**: `fastv.xcodeproj/project.pbxproj` (INFOPLIST_KEY_NSAppleEventsUsageDescription)
- **说明**: 通过代码自动请求（`TextInsertionService.requestAccessibilityPermission()`）
- **重要**: 这是**必需的权限**，没有此权限无法在其他应用中输入文字

## 权限请求流程

### 麦克风权限
1. **首次启动**: 应用启动时会自动请求麦克风权限
2. **首次使用**: 如果首次启动时未授权，在尝试录音时会再次提示
3. **权限被拒绝**: 应用会显示错误提示，引导用户到系统设置中授权

### 辅助功能权限
1. **自动请求**: 首次启用语音输入功能时，代码会自动请求权限
2. **系统对话框**: macOS 会弹出系统对话框，提示用户授权
3. **手动授权**: 如果用户点击"打开系统偏好设置"，需要在"系统设置 > 隐私与安全性 > 辅助功能"中手动添加应用

## 用户操作指南

### 授予麦克风权限
1. 首次启动应用时，系统会弹出权限请求对话框
2. 点击"好"或"允许"即可

### 授予辅助功能权限
1. 首次启用语音输入功能时，系统会弹出权限请求对话框
2. 点击"打开系统偏好设置"
3. 在"系统设置 > 隐私与安全性 > 辅助功能"中找到 "fastv"
4. 勾选应用旁边的复选框

## 验证权限状态

应用会在以下位置检查权限状态：
- **麦克风权限**: `AVCaptureDevice.authorizationStatus(for: .audio)`
- **辅助功能权限**: `AXIsProcessTrustedWithOptions()`

## 权限详细说明

### 为什么需要辅助功能权限？

辅助功能权限允许应用：
1. **监听全局快捷键** - 在任何应用中按下快捷键时都能响应
2. **模拟键盘输入** - 使用 `CGEvent` API 模拟按键操作
3. **访问剪贴板** - 虽然 NSPasteboard 本身不需要权限，但配合模拟粘贴操作需要辅助功能权限

### 文本插入的工作原理

应用使用以下方式将文本插入到其他应用：
1. 将识别文本复制到系统剪贴板
2. 模拟按下 `Cmd+V` 快捷键
3. 目标应用接收到粘贴命令，插入文本
4. 恢复剪贴板原有内容

这种方式需要辅助功能权限才能模拟键盘事件。

## 注意事项

⚠️ **重要提示**:
- **辅助功能权限是必需的**，否则无法：
  - 监听全局快捷键
  - 在其他应用中自动输入文字
  - 使用剪贴板+粘贴的方式插入文本
- 如果权限被拒绝，语音输入功能将无法正常工作
- 用户可以在"系统设置 > 隐私与安全性 > 辅助功能"中随时修改权限设置
- 修改权限后，需要重启应用才能生效
- 首次使用时，系统会自动弹出权限请求对话框

## 故障排除

如果权限无法正常工作：

1. **检查系统设置**:
   - 打开"系统设置 > 隐私与安全性"
   - 检查"麦克风"和"辅助功能"中是否已授权 fastv

2. **重新授权**:
   - 取消勾选应用
   - 重新勾选应用
   - 重启应用

3. **检查应用日志**:
   - 查看控制台输出，确认权限请求是否成功
