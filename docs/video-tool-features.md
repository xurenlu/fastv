## 🎯 核心功能（重点开发）

以下是本工具的**核心差异化功能**，优先实现：

### 1. 🎨 颜色调整

对视频画面进行专业级色彩调整：

| 功能 | 说明 | 应用场景 |
|------|------|---------|
| 亮度/对比度 | 调整画面明暗层次 | 修正曝光不足/过曝 |
| 饱和度 | 调整色彩浓淡 | 增强/减弱色彩表现力 |
| 色温调整 | 冷暖色调切换 | 校正白平衡、营造氛围 |
| 色调偏移 | 整体色相调整 | 艺术风格化 |
| LUT 调色 | 应用专业调色预设 | 电影感、复古风等 |

**实现方式**：FFmpeg `eq`、`hue`、`colortemperature`、`lut3d` 滤镜

```bash
# 示例：增加亮度和饱和度
ffmpeg -i input.mp4 -vf "eq=brightness=0.1:saturation=1.3" output.mp4

# 示例：应用 LUT 调色
ffmpeg -i input.mp4 -vf "lut3d=cinematic.cube" output.mp4
```

### 2. 📐 智能横竖屏转换

将横屏视频智能转换为竖屏（或反向），自动追踪主体：

| 转换类型 | 说明 | 技术要点 |
|---------|------|---------|
| 横屏→竖屏 | 16:9 → 9:16 | 智能裁剪，追踪人物主体 |
| 竖屏→横屏 | 9:16 → 16:9 | 背景模糊填充 |
| 宽银幕→标准 | 21:9 → 16:9 | 智能裁剪关键区域 |

**实现流程**：

```
┌─────────────────────────────────────────────────────────┐
│ 1. 抽取关键帧（每秒 1-2 帧）                              │
├─────────────────────────────────────────────────────────┤
│ 2. YOLO/人脸检测 → 识别主体位置                          │
├─────────────────────────────────────────────────────────┤
│ 3. 计算每帧最佳裁剪窗口                                  │
├─────────────────────────────────────────────────────────┤
│ 4. 平滑插值 → 避免画面跳跃                               │
├─────────────────────────────────────────────────────────┤
│ 5. 生成 FFmpeg 动态裁剪脚本                              │
├─────────────────────────────────────────────────────────┤
│ 6. FFmpeg 应用裁剪 → 输出竖屏视频                        │
└─────────────────────────────────────────────────────────┘
```

**技术实现**：
- Go + ONNX Runtime 运行 YOLOv8 检测人物
- 计算主体中心点，生成裁剪坐标序列
- 使用移动平均平滑坐标变化
- FFmpeg `crop` 滤镜 + `sendcmd` 动态参数

### 3. 🌫️ 渐变式抹除马赛克

不是生硬的马赛克遮挡，而是像"被抹掉"一样自然融入背景：

| 效果类型 | 说明 | 视觉效果 |
|---------|------|---------|
| 传统马赛克 | 像素块遮挡 | 生硬、明显 |
| 高斯模糊 | 单纯模糊 | 稍好，但边缘明显 |
| **渐变式抹除** | 多层模糊 + 边缘羽化 | 自然融入，像"消失"了 |

**实现原理**：

```
┌────────────────────────────────────────┐
│           原始画面                      │
│    ┌──────────────────┐                │
│    │   目标区域        │                │
│    │  ┌────────────┐  │                │
│    │  │ 核心区域    │  │ ← 强模糊 σ=50 │
│    │  │ (最模糊)    │  │                │
│    │  └────────────┘  │                │
│    │   过渡区域        │ ← 中等模糊 σ=30│
│    │  (渐变透明度)     │                │
│    └──────────────────┘                │
│         边缘羽化        ← 轻微模糊 σ=10 │
└────────────────────────────────────────┘
```

**FFmpeg 实现**：

```bash
# 渐变式抹除效果
ffmpeg -i input.mp4 -vf "
  split[main][blur];
  [blur]crop=200:200:x:y,
       gblur=sigma=50,
       vignette=PI/4,
       scale=240:240[blurred];
  [main][blurred]overlay=x-20:y-20:format=auto
" output.mp4
```

**高级实现（Go + AI）**：
- 可选使用 Inpainting 模型（如 LaMa）进行内容感知填充
- 用周围像素"修复"目标区域，效果更自然

### 4. 🏷️ 添加 Logo/水印

在视频固定位置添加 Logo 图片和文字水印：

| 功能 | 说明 | 应用场景 |
|------|------|---------|
| 图片 Logo | PNG/透明背景图片 | 品牌标识 |
| 文字水印 | 自定义文字 | 版权声明 |
| 位置控制 | 九宫格定位 + 偏移量 | 灵活放置 |
| 透明度 | 0-100% 可调 | 不影响观看 |
| 时间戳 | 自动显示当前时间 | 监控/记录 |

**位置参数**：

```
┌─────────┬─────────┬─────────┐
│ 左上    │  上中    │   右上   │
│ (0,0)   │ (居中,0) │ (右,0)  │
├─────────┼─────────┼─────────┤
│ 左中    │   中心   │   右中   │
├─────────┼─────────┼─────────┤
│ 左下    │  下中    │   右下   │
│ (0,底)  │ (居中,底)│ (右,底) │
└─────────┴─────────┴─────────┘
```

**FFmpeg 实现**：

```bash
# 右下角添加 Logo（距边缘 20px，50% 透明度）
ffmpeg -i input.mp4 -i logo.png -filter_complex "
  [1:v]format=rgba,colorchannelmixer=aa=0.5[logo];
  [0:v][logo]overlay=W-w-20:H-h-20
" output.mp4

# 添加文字水印
ffmpeg -i input.mp4 -vf "
  drawtext=text='© 2024 MyBrand':
  x=W-tw-20:y=H-th-20:
  fontsize=24:fontcolor=white@0.7:
  borderw=2:bordercolor=black@0.5
" output.mp4
```

| 缩放 | 等比/非等比缩放 | `scale=w:h` |

| 功能 | 说明 | FFmpeg 滤镜 |
|------|------|------------|
| 亮度/对比度 | 调整画面明暗 | `eq=brightness=0.1:contrast=1.2` |
| 饱和度 | 调整色彩浓度 | `eq=saturation=1.5` |

| 功能 | 说明 | 实现方式 |
|------|------|---------|

| 竖屏→横屏 | 9:16 → 16:9 | 背景模糊填充 |

| 自动居中 | 追踪主体居中 | 人脸/物体检测 |

**实现思路**：
```
1. 抽取关键帧
2. 用本地 AI 检测人脸/主体位置
3. 计算最佳裁剪区域
4. 平滑过渡避免跳跃
5. FFmpeg 应用裁剪
```

## 🎭 三、智能处理（本地 AI）

### 渐变式抹除（重点）

不是生硬的马赛克，而是像"被抹掉"的感觉：

```
原理：
1. 目标区域应用强模糊（sigma=50）
2. 边缘使用径向渐变透明度
3. 可选：用周边像素进行 inpainting 填充
4. 结果：看起来像"融入背景"而非"遮挡"
```

FFmpeg 实现：
```bash
# 柔和抹除效果
-vf "split[main][blur]; \
     [blur]crop=200:200:x:y, \
     gblur=sigma=40, \
     vignette=PI/4[blurred]; \
     [main][blurred]overlay=x:y:format=auto"
```
