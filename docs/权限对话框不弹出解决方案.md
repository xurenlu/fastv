# 权限对话框不弹出解决方案

## 🔍 问题分析

你遇到的情况：
```
🎤 [fastvApp] 当前麦克风权限状态: 0 (未确定)
🎤 [fastvApp] 权限未确定，请求麦克风权限...
💡 [fastvApp] 提示：系统将弹出权限请求对话框，请点击'好'授权
❌ [fastvApp] 麦克风权限被拒绝  ← 立即显示，说明对话框没弹出
```

### 原因

1. **之前可能拒绝过权限**，macOS记住了这个选择
2. **权限数据库中有旧记录**，阻止了对话框弹出
3. **对话框在后台**，被其他窗口遮挡

## ✅ 已执行的修复

### 1. 重置权限数据库 ✅

已执行命令：
```bash
tccutil reset Microphone com.wxside.fastv
```

结果：
```
Successfully reset Microphone approval status for com.wxside.fastv
```

这会清除应用的麦克风权限记录，让系统重新请求。

### 2. 改进权限请求逻辑 ✅

- 添加了详细的状态描述
- 添加了用户响应后的提示
- 如果用户拒绝，会弹出引导对话框

### 3. 编译成功 ✅

应用已重新编译，包含所有修复。

## 🔧 如果对话框还是不弹出

### 方案A：检查系统设置

1. 打开"系统设置"
2. "隐私与安全性" → "麦克风"
3. 查看列表中是否有 fastv
4. 如果有，删除它（点击 - 号）
5. 重新运行应用

### 方案B：手动添加权限

1. 打开"系统设置"
2. "隐私与安全性" → "麦克风"
3. 点击 + 号
4. 找到并添加 fastv.app
5. 确保勾选

### 方案C：重新编译（使用不同的Bundle ID）

如果上述方法都不行，可能是Bundle ID的问题。

查看当前Bundle ID：
```bash
defaults read /Users/rocky/Library/Developer/Xcode/DerivedData/fastv-bsagblddbizlhxceqjtyzxtsgyzo/Build/Products/Debug/fastv.app/Contents/Info.plist CFBundleIdentifier
```

应该显示：`com.wxside.fastv`

### 方案D：检查是否有其他限制

```bash
# 检查TCC数据库
sqlite3 ~/Library/Application\ Support/com.apple.TCC/TCC.db "SELECT * FROM access WHERE service='kTCCServiceMicrophone' AND client='com.wxside.fastv';"
```

如果有记录且 `allowed=0`，说明被拒绝了。
