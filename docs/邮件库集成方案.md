# 邮件库集成方案

## 方案对比

### 方案 1：使用 MailKit（Apple 官方，推荐）⭐

**优点：**
- Apple 官方支持，稳定可靠
- 原生 Swift API，易于使用
- 支持 IMAP、SMTP
- 自动处理加密和认证

**缺点：**
- 需要 macOS 12.0+（你的项目是 macOS 11.0+）
- 需要 App Sandbox 权限配置

**实现步骤：**
1. 在 Xcode 中添加 MailKit framework
2. 在 entitlements 中添加邮件权限
3. 使用 MailKit 的 API

### 方案 2：手动集成 MailCore2（从源码编译）

**优点：**
- 功能完整，支持所有协议
- 支持 macOS 11.0+

**缺点：**
- 需要手动编译 C++ 库
- 需要创建桥接头文件
- 维护成本较高

**实现步骤：**
1. 从 GitHub 下载 MailCore2 源码
2. 编译静态库
3. 添加到项目并创建桥接头

### 方案 3：使用邮件服务 REST API（最简单）⭐

**优点：**
- 不需要底层协议实现
- 使用标准的 HTTPS 请求
- 支持 Gmail、Outlook、阿里云等

**缺点：**
- 需要 OAuth 认证
- 不同服务商 API 不同
- 功能可能有限制

**支持的 API：**
- Gmail API：https://developers.google.com/gmail/api
- Microsoft Graph API（Outlook）：https://learn.microsoft.com/en-us/graph/overview
- 阿里云邮件推送 API

### 方案 4：使用 LibEtPan（C 库）+ Swift 封装

**优点：**
- 底层库，功能强大
- 跨平台支持

**缺点：**
- 需要 C 桥接
- 集成复杂

## 推荐方案

### 短期方案：使用邮件服务 REST API

对于快速实现，建议先使用 Gmail API 或 Microsoft Graph API：

1. **Gmail API**：
   - 使用 Google OAuth 2.0 认证
   - RESTful API，易于集成
   - 支持 IMAP 风格的邮件操作

2. **Microsoft Graph API**：
   - 支持 Outlook/Hotmail
   - 统一的 API 接口
   - OAuth 2.0 认证

### 长期方案：升级到 MailKit

如果你的项目可以升级到 macOS 12.0+，强烈建议使用 MailKit：

```swift
import MailKit

// MailKit 提供了完整的邮件客户端功能
// 包括账号管理、邮件收发、文件夹同步等
```

## 代码示例：Gmail API 集成

```swift
// 使用 Gmail API 获取邮件列表
func fetchGmailMessages() async throws -> [EmailMessage] {
    let url = URL(string: "https://gmail.googleapis.com/gmail/v1/users/me/messages")!
    var request = URLRequest(url: url)
    request.setValue("Bearer \(accessToken)", forHTTPHeaderField: "Authorization")
    
    let (data, _) = try await URLSession.shared.data(for: request)
    let response = try JSONDecoder().decode(GmailMessagesResponse.self, from: data)
    
    // 转换为 EmailMessage
    return try await convertGmailMessages(response.messages)
}
```
