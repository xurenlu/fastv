# 证书私钥问题说明

## 问题

证书已安装，但无法用于签名，错误信息：
```
no identity found
```

## 原因

**Developer ID 证书缺少对应的私钥**。证书文件（.cer）只包含公钥，签名需要私钥。

## 解决方案

### 方案 1：如果有私钥文件（.p12 或 .key）

如果您有私钥文件，需要导入：

```bash
# 导入 .p12 文件（包含证书和私钥）
security import certificate.p12 -k ~/Library/Keychains/login.keychain-db -P "密码"

# 或导入私钥文件
security import private_key.key -k ~/Library/Keychains/login.keychain-db
```

### 方案 2：重新申请证书（如果私钥丢失）

如果私钥不在当前 Mac 上，需要：

1. **撤销旧证书**
   - 访问：https://developer.apple.com/account/resources/certificates/list
   - 找到对应的证书并撤销

2. **生成新的 CSR**
   ```bash
   ./generate_csr.sh "your-email@example.com" "Your Name"
   ```

3. **重新申请证书**
   - 上传新的 CSR 文件
   - 下载新证书

4. **安装证书**
   - 双击安装，私钥会自动匹配（因为 CSR 是在本机生成的）

### 方案 3：从其他 Mac 导出证书和私钥

如果证书和私钥在另一台 Mac 上：

1. **在源 Mac 上导出**
   - Keychain Access > 找到证书
   - 右键 > Export
   - 选择格式：Personal Information Exchange (.p12)
   - 设置密码

2. **在当前 Mac 上导入**
   ```bash
   security import certificate.p12 -k ~/Library/Keychains/login.keychain-db -P "密码"
   ```

## 验证私钥是否存在

运行以下命令检查：

```bash
# 检查证书
security find-certificate -a -c "Developer ID Application" -Z

# 检查私钥
security find-key -c "Developer ID Application"

# 检查完整的签名身份（证书+私钥）
security find-identity -v -p codesigning | grep "Developer ID"
```

如果 `security find-identity` 没有显示 Developer ID，说明缺少私钥。

## 当前状态

- ✅ 证书已安装（.cer 文件）
- ❌ 私钥缺失
- ❌ 无法用于签名

## 下一步

请确认：
1. 您是否有证书对应的私钥文件（.p12 或 .key）？
2. 证书是在当前 Mac 上申请的吗？
3. 如果是公司证书，私钥是否在其他同事的 Mac 上？

根据情况选择合适的方案。
