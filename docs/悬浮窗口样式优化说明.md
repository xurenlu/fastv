# 悬浮窗口样式优化说明

## ✨ 新增功能

### 1. 可自定义的窗口大小

在"设置" → "语音输入法"中，新增**"悬浮工具条大小"**选项：

| 样式 | 尺寸 | 特点 |
|------|------|------|
| **紧凑** | 80×28 | 默认，最小最精致，转文字时不显示文字 |
| 正常 | 100×32 | 中等大小，显示"转文字中…" |
| 大 | 120×40 | 最大，所有元素都更明显 |

### 2. 可自定义的颜色风格 🎨

新增**"悬浮工具条颜色"**选项：

- 🔵 蓝色（默认，系统强调色）
- 🟣 紫色
- 🩷 粉色
- 🟢 绿色
- 🟠 橙色
- 🔴 红色

### 3. 立即切换动画 ⚡

**优化前的问题：**
- 松开快捷键后，动画切换有延迟
- 用户不确定是否已经进入转文字阶段

**优化后：**
- 在 `handleShortcutReleased()` 中，**先切换动画**，再停止录音
- 添加 50ms 的短暂延迟，确保 UI 更新完成
- 使用 `.id(state)` 强制重新创建视图
- 弹簧动画（0.3秒响应）让过渡更流畅

**效果：**
- 松开快捷键的瞬间，波形动画立即变成旋转加载动画
- 视觉反馈非常明确，用户立即知道已进入转文字阶段

### 4. 优化内边距

各个样式的内边距都已优化，减少空白空间：

| 样式 | 横向内边距 | 纵向内边距 |
|------|-----------|-----------|
| 紧凑 | 6px | 4px |
| 正常 | 8px | 5px |
| 大 | 10px | 6px |

波形条之间的间距也相应调整：
- 紧凑：2px
- 正常：3px
- 大：4px

## 🎨 视觉效果

### 半透明毛玻璃

- **材质**：`.ultraThinMaterial`（超薄毛玻璃）
- **黑色遮罩**：15% 不透明度，增强对比度
- **渐变边框**：白色渐变（30%→10%）
- **阴影**：12pt 模糊，6pt 偏移，25% 不透明度

### 录音状态

- **波形条**：使用选定颜色的渐变（实色→60% 透明度）
- **动画**：实时跟随音量变化
- **流畅过渡**：0.3秒缓动

### 转文字状态

- **背景圆环**：选定颜色的 20% 透明度
- **旋转圆环**：角度渐变（实色→10% 透明度）
- **旋转速度**：0.9秒一圈
- **文字提示**：圆润字体，9-10px（紧凑模式不显示）

## 📱 使用方法

### 设置样式

1. 打开应用
2. 进入"设置" → "语音输入法"
3. 找到以下选项：
   - **悬浮工具条位置**：右上角/左上角/底部居中等
   - **悬浮工具条大小**：紧凑/正常/大
   - **悬浮工具条颜色**：蓝/紫/粉/绿/橙/红
4. 选择后立即生效

### 推荐配置

**最小最精致：**
- 大小：紧凑
- 颜色：蓝色或紫色
- 位置：右上角

**平衡配置：**
- 大小：正常
- 颜色：绿色或橙色
- 位置：底部居中

**最醒目：**
- 大小：大
- 颜色：红色或粉色
- 位置：左上角

## 🔧 技术实现

### 动画立即切换

```swift
// 在 handleShortcutReleased() 中
waveformManager.setTranscribing()  // 立即切换状态
try? await Task.sleep(nanoseconds: 50_000_000)  // 50ms让UI更新
// 然后再停止录音和转文字
```

### 强制视图重建

```swift
.id(state)  // 状态改变时强制重新创建视图
.animation(.spring(response: 0.3, dampingFraction: 0.7), value: state)
```

### 响应式尺寸

```swift
let style = UserPreferences.shared.waveformWindowStyle
let size = style.size
// 所有元素都根据 style 动态调整
```

3. **个性化**：根据系统主题选择喜欢的颜色
4. **多显示器**：可以为不同显示器设置不同位置
