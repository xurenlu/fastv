## 🚀 使用构建脚本

### 1. 构建和签名

```bash
# 给脚本添加执行权限
chmod +x build_and_sign.sh

# 运行构建脚本
./build_and_sign.sh
```

脚本会自动：
- ✅ 检查证书
- ✅ 清理旧的构建文件
- ✅ 构建 Archive
- ✅ 导出应用（使用 Developer ID 签名）
- ✅ 验证签名
- ✅ （可选）创建 DMG 安装包

### 2. 公证应用（推荐）

公证可以让 macOS Gatekeeper 完全信任您的应用，用户安装时不会看到任何警告。

**创建 App-Specific Password：**
1. 访问：https://appleid.apple.com
2. 登录 > App-Specific Passwords
3. 创建密码用于公证

**进行公证：**
```bash
# 给脚本添加执行权限
chmod +x notarize.sh

# 公证应用
./notarize.sh build/export/typecho.app your-email@example.com W49B66SUW3 app-specific-password

# 或公证 DMG
./notarize.sh build/typecho.dmg your-email@example.com W49B66SUW3 app-specific-password
```

## 📝 手动操作步骤

如果不想使用脚本，可以手动操作：

### 1. 在 Xcode 中 Archive

1. 打开 Xcode
2. 选择 Product > Scheme > Edit Scheme
3. 选择 "Archive"
4. 确保 "Build Configuration" 为 "Release"
5. Product > Archive
6. 等待构建完成

### 2. 导出应用

1. 在 Organizer 窗口中选择 Archive
2. 点击 "Distribute App"
3. 选择 "Developer ID"（不是 App Store）
4. 选择导出方式：
   - **Export** - 导出到本地
   - **Upload** - 上传到 App Store Connect（不适用于直接分发）
5. 按照向导完成导出

### 3. 验证签名

```bash
# 检查签名信息
codesign -dvv /path/to/typecho.app | grep -E "Authority=|TeamIdentifier="

# 验证签名
codesign -v /path/to/typecho.app

# 检查 Gatekeeper 状态
spctl -a -vv /path/to/typecho.app
```

### 4. 公证（可选但推荐）

```bash
# 创建 ZIP（对于 .app）
ditto -c -k --keepParent typecho.app typecho.zip

# 提交公证
xcrun notarytool submit typecho.zip \
  --apple-id "your-email@example.com" \
  --team-id "W49B66SUW3" \
  --password "app-specific-password" \
  --wait

# 装订公证票据
xcrun stapler staple typecho.app

# 验证公证
xcrun stapler validate typecho.app
```

## ⚠️ 重要注意事项

### 1. 证书 Team ID 匹配

**必须确保：**
- 项目配置的 Team ID 与证书的 Team ID 匹配
- 证书对应的私钥在您的 Mac 上
- 证书未过期

### 2. Entitlements 配置

当前 `fastv.entitlements` 包含 `get-task-allow`，这是调试权限：
- ✅ Debug 配置：会自动包含
- ✅ Release 配置：Xcode 会自动移除（用于分发）

### 3. 动态库签名

项目中的 ONNX Runtime 动态库也需要正确签名。构建脚本中的 "Sign ONNX Runtime Library" 阶段会自动处理。

### 4. 权限请求

即使用 Developer ID 签名，首次运行时：
- ✅ 权限请求对话框会正常弹出
- ⚠️ 辅助功能权限仍需要用户在系统设置中手动授权

## 🔍 故障排查

### 问题 1：证书 Team ID 不匹配

**错误信息：**
```
code signature in ... not valid for use in process: mapping process and mapped file (non-platform) have different Team IDs
```

**解决方案：**
- 确保项目配置的 Team ID 与证书匹配
- 或使用正确的证书

### 问题 2：签名验证失败

**检查：**
```bash
# 查看详细签名信息
codesign -dvv typecho.app

# 验证签名
codesign -v typecho.app

# 检查所有签名
codesign --verify --deep --strict --verbose=2 typecho.app
```

### 问题 3：Gatekeeper 阻止运行

**解决方案：**
1. 使用 Developer ID 证书签名（不是开发证书）
2. 进行公证
3. 装订公证票据

### 问题 4：公证失败

**常见原因：**
- App-Specific Password 错误
- Team ID 不匹配
- 应用签名有问题

**检查：**
```bash
# 查看公证日志
xcrun notarytool log <submission-id> \
  --apple-id "your-email@example.com" \
  --team-id "W49B66SUW3" \
  --password "app-specific-password"
```
